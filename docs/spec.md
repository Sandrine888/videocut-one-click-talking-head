# Videocut - 需求规范

> 版本: v1.0
> 创建时间: 2026-01-17

---

## 1. 概述

### 1.1 背景
口播视频创作者在录制后需要大量时间剪辑：识别口误、删除静音、重复内容等。这个过程繁琐且耗时，一个5分钟的视频可能需要30分钟以上的剪辑时间。

### 1.2 目标
提供一个智能口播视频剪辑工具，自动识别口误和冗余内容，一键生成精剪视频，将剪辑时间从30分钟缩短到3分钟。

### 1.3 目标用户
- 短视频创作者
- 知识博主
- 培训讲师
- 播客主播

## 2. 用户故事

### 故事 1: 首次安装配置
**作为** 一个刚购买软件的用户
**我想要** 通过简单的交互完成初始配置
**以便于** 快速开始使用工具

**验收标准**:
- [ ] 通过 `pip install videocut` 完成安装
- [ ] 运行 `videocut init` 进入交互式配置
- [ ] 能验证 License Key 并激活软件
- [ ] 能配置 AI 服务（选择提供商、输入 API Key、测试连接）
- [ ] 能选择默认输出方式（本地/剪映）
- [ ] 自动检测并安装必要依赖

### 故事 2: 剪辑口播视频
**作为** 一个录完视频的创作者
**我想要** 用一条命令自动剪辑视频
**以便于** 快速得到可发布的成品

**验收标准**:
- [ ] 运行 `videocut cut video.mp4` 开始处理
- [ ] 自动转录视频内容并显示进度
- [ ] AI 分析文案，生成2个重组方案供选择
- [ ] 自动识别口误、语气词、长静音
- [ ] 显示删除任务清单，用户确认后执行
- [ ] 输出剪辑后的视频文件

### 故事 3: 查看 License 状态
**作为** 一个付费用户
**我想要** 查看我的 License 使用情况
**以便于** 了解剩余有效期和设备数

**验收标准**:
- [ ] 运行 `videocut status` 查看状态
- [ ] 显示 License 有效期
- [ ] 显示已激活设备数/最大设备数
- [ ] 显示当前配置信息

### 故事 4: 修改配置
**作为** 一个想更换 AI 服务的用户
**我想要** 修改已保存的配置
**以便于** 切换到其他 LLM 提供商

**验收标准**:
- [ ] 运行 `videocut config` 进入配置菜单
- [ ] 能修改 AI 服务配置
- [ ] 能修改默认输出方式
- [ ] 修改后测试新配置是否有效

## 3. 功能需求

### 3.1 核心功能

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| F1 | 初始化配置 | License 验证、AI 配置、输出选择 | P0 |
| F2 | 视频转录 | 将视频语音转为带时间戳的文字 | P0 |
| F3 | AI 文案重组 | 分析转录文案，生成精简方案 | P0 |
| F4 | 口误识别 | 识别口误、语气词、长静音 | P0 |
| F5 | 视频剪辑 | 根据删除任务剪辑视频 | P0 |
| F6 | 本地输出 | 烧录字幕，输出成品视频 | P0 |
| F7 | 剪映输出 | 推送到剪映草稿箱 | P1 |
| F8 | License 验证 | 在线验证 License 有效性 | P0 |
| F9 | 配置管理 | 查看/修改配置 | P1 |
| F10 | 状态查询 | 查看 License 和配置状态 | P2 |

### 3.2 功能详情

#### F1: 初始化配置
- **输入**: License Key、LLM 配置、输出方式选择
- **输出**: 配置文件、激活确认
- **约束**: License 必须在线验证通过

#### F2: 视频转录
- **输入**: 视频文件路径
- **输出**: 带字符级时间戳的转录文本
- **约束**: 支持 mp4/mov/avi 格式

#### F3: AI 文案重组
- **输入**: 转录文本
- **输出**: 2个重组方案（含删除建议）
- **约束**: 依赖用户配置的 LLM 服务

#### F4: 口误识别
- **输入**: 转录文本（带时间戳）
- **输出**: 口误清单（含精确时间戳）
- **约束**: 识别重复型、替换型、卡顿型口误

#### F5: 视频剪辑
- **输入**: 原视频 + 删除任务清单
- **输出**: 剪辑后视频
- **约束**: 保持画质，无损剪辑

#### F6: 本地输出
- **输入**: 剪辑后视频 + 字幕
- **输出**: 烧录字幕的成品视频
- **约束**: 字幕样式可配置

#### F7: 剪映输出
- **输入**: 剪辑后视频
- **输出**: 剪映草稿箱中的项目
- **约束**: 需要剪映已安装

## 4. 非功能需求

### 4.1 性能要求
- 5分钟视频转录时间 < 2分钟
- 剪辑执行时间 < 1分钟
- License 验证响应 < 3秒

### 4.2 可用性要求
- 支持 macOS 和 Windows
- 命令简洁，主流程只需一条命令
- 有清晰的进度提示
- 有完整的帮助信息

### 4.3 安全要求
- 用户 API Key 加密存储
- License 验证使用 HTTPS
- 不上传用户视频内容

---

## 5. 边界与约束

### 5.1 不在范围内（Out of Scope）
- 不支持实时直播处理
- 不支持多人协作
- 不支持视频特效
- 不支持 Web 界面（本版本）
- 不支持批量处理（本版本）

### 5.2 假设条件
- 用户已安装 Python 3.8+
- 用户已安装 FFmpeg
- 用户有可用的 LLM API Key
- 用户设备有网络连接（用于 License 验证）

### 5.3 依赖项
- Supabase（License 验证服务）
- 用户选择的 LLM 服务（OpenAI/Claude/其他）
- FFmpeg（视频处理）
- 语音识别模型（本地运行）

### 6.1 验收标准
- [ ] `pip install videocut` 安装成功
- [ ] `videocut init` 完成配置流程
- [ ] `videocut cut video.mp4` 成功剪辑视频
- [ ] 支持 macOS 和 Windows
- [ ] License 在线验证正常工作
- [ ] AI 文案重组生成有效方案
- [ ] 口误识别准确率 > 90%

### 6.2 MVP 定义
最小可行产品包含：
1. License 验证（F8）
2. 初始化配置（F1）
3. 视频转录（F2）
4. 口误识别（F4）
5. 视频剪辑（F5）
6. 本地输出（F6）

MVP 不包含：AI 文案重组、剪映输出

## 7. 附录

### 7.1 命令示例

```bash
# 安装
$ pip install videocut

# 首次配置
$ videocut init
欢迎使用 Videocut 口播视频剪辑工具！
第1步：License 验证
请输入 License Key: VC-XXXX-XXXX-XXXX
✓ License 验证成功

# 剪辑视频
$ videocut cut 口播视频.mp4
[1/5] 转录视频...
✓ 转录完成，共 2006 字
[2/5] AI 文案重组...
...
✓ 输出：口播视频_cut.mp4

# 查看状态
$ videocut status
License: VC-XXXX-XXXX-XXXX
状态: 有效
到期: 2027-01-17
设备: 1/2

# 修改配置
$ videocut config
```

### 7.2 术语表

| 术语 | 定义 |
|------|------|
| 口误 | 说错后重新说的内容，需要删除前面错误的部分 |
| 语气词 | 嗯、啊、哎等填充词 |
| 时间戳 | 每个字/词在视频中的起止时间 |
| 文案重组 | AI 分析原始文案，去除冗余，重新组织结构 |
